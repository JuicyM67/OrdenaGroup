# WP-23 Väntelista (F8) + WP-30 Horas flash (F13) — ägaren 2026-10-01

## Väntelista
- `waitlist_entries` (business_id, customer_id, service_id, day date, staff_id null, status waiting|offered|booked|expired|removed, offered_at, offer_expires_at, offer_token_hash, created_at). RLS: medlemmar läser; skriv via servern (service_role) + ägare/can_manage_all_bookings tar bort.
- `businesses.waitlist_mode text 'sequential'|'broadcast' default 'sequential'`, `waitlist_hold_minutes smallint default 30` (5–240).
- Kund går med från /[slug] när dagen är full (befintligt joinWaitlist-stub + kort). Kräver samtyckesrutan "waitlist" (finns) och telefon.
- När en tid frigörs (avbokning, nekad/utgången förfrågan, godkänd avbokning, flytt) → matcha väntande för samma tjänst och dag (och staff om angiven, och att tiden passar tjänstens längd) → sequential: en i taget, nästa efter hold; broadcast: alla samtidigt. Meddelande SE sms + e-post, CL e-post. Länk `/v/[token]` → "Ta tiden" (POST) bokar atomärt (exclusion constraint), övriga får "redan tagen"-sida/besked. Bokningen blir confirmed (företaget har redan godkänt kön) — eller requested om auto-confirm av? Välj: följ företagets auto_confirm.
- Utgång: cron/outbox-svepet hanterar offered → expired och nästa i turordning.
- UI: väntelistkort i Agenda/Hoy med antal + lista per dag, ägaren kan ta bort; Inställningar → Bokningsregler: läge + hålltid.

## Horas flash
- `flash_slots` (business_id, staff_id, start timestamptz, end, service_ids uuid[] null = alla, discount_pct 1–90, status active|booked|cancelled, booking_id null, created_by). Tiden måste vara ledig; bokas den → booked.
- Ägaren skapar från Agenda (tomt fält / knapp "Blixttid") och från Hoy; listar aktiva på /app/flash (återinför navigeringen "Horas flash", tidigare dold D-035).
- /[slug] visar flash-tider med märke + nedsatt pris (server); `/{slug}?flash=<id>` förväljer. createIn: rabatt = största av flash/medlem/erbjudande; flash_slot → booked i samma transaktion.
- Story-bild: `/api/flash/[id]/story.png` via next/og enligt docs/design/reference/HoraFlash*.dc.html (1080×1920).
- "Skicka till kunder": återanvänd WP-31 sendCampaign med länk till flash-tiden (målgrupp: alla med samtycke / medlemmar / stamkunder).
- Agenda: flash-tider markerade (befintlig legend "Flashtider").
